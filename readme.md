# P1 Creative Software Developer - Basis Programmeren

Dit is het basis project voor Creative Software Developer (CSD), jaar 1, periode 1, voor het Grafisch Lyceum Utrecht.

## Wat zit er in dit project?

Dit project bevat een basisstructuur voor verschillende opdrachten en oefeningen. De week-opdrachten hebben al mapjes, net zoals de oefenopdrachten. Zo kun je per opdracht eenvoudig werken in een aparte map.

## Hoe start je het project?

Je kunt dit project draaien met de p5.js extension en Live Server in Visual Studio Code.

Stappen:
1. Open de map in Visual Studio Code.
2. Installeer de p5.js extension.
3. Start Live Server.
4. Open de browser om de opdrachten te zien.
5. Kies je huidige opdracht uit de lijst en test dit project.

## Project aanmaken

Je moet dit project __forken__ en een duidelijke naam geven aan het project. Een goede naam is bijvoorbeeld:

- p1-[Michael]-[van Eijnsbergen]
- p1-[260649]

Zo blijft het overzichtelijk en herkenbaar voor de docent.

## Instructies

- Werk per opdracht in de juiste map.
- Gebruik comments in je code om je proces te verduidelijken.
- Maak regelmatig commits zodat je voortgang bewaart.

Veel succes met de opdrachten!
